# בדיקות בלייב — העובדת testing

עובדת קבועה לבדיקות **בשרת האמיתי** (Firestore של `shaon-ovdot-2c10`), כדי לבדוק כל שינוי באפליקציות על נתונים אמיתיים.
הנתונים שלה נשארים בכוונה — לא למחוק אותם.

| מה | ערך |
|---|---|
| שם העובדת | `testing` (תעריף 50 ₪) |
| מזהה עובדת | `TESTINGqa0emp000000001` |
| חשבון המנהל | `qosj8BiaXERmxYLJLXvjodf9P0v1` (החשבון שבו מחוברים הטלפונים) |
| טלפון הבדיקה | אמולטור Android בשם `shaon_test`, מחובר כעובדת testing |
| מזהים של נתוני בדיקה | מתחילים ב-`QA` (תשלומים, משמרות שנוצרו מאישור, משמרת שנשארה פתוחה) |

## דרישות
- התחברות ל-Firebase CLI עם החשבון של הפרויקט: `npx firebase-tools login`
- Android SDK (‏`adb`, ‏`emulator`)

## הרצת האמולטור ובניית האפליקציה

</div>

```bash
~/Library/Android/sdk/emulator/emulator -avd shaon_test -no-audio &
```

```bash
cd android && ./gradlew assembleDebug && adb install -r app/build/outputs/apk/debug/app-debug.apk
```

<div dir="rtl" align="right">

אם האמולטור התנתק (למשל אחרי `disconnect`): ‏`node tools/live-test/live.mjs code` ולהקליד את הקוד באפליקציה.
אחרי הסרה והתקנה מחדש האפליקציה מתחברת לבד (כרטיס שחזור).

## פעולות "מנהל" מהטרמינל

</div>

```bash
node tools/live-test/live.mjs status
```

<div dir="rtl" align="right">

| פקודה | מה היא עושה |
|---|---|
| `status` | כל מה שיש לעובדת בשרת: טלפון, משמרות, בקשות, הודעות, תשלומים |
| `totals [YYYY-MM]` | סיכום החודש לפי `public/pay.js` — להשוות למסך "החודש שלי" בטלפון |
| `code` | קוד חיבור חדש לטלפון (תקף 14 דקות) |
| `approve` / `reject` | אישור/דחייה של הבקשה הממתינה הכי ישנה (כמו באפליקציית המק) |
| `pay <shiftId>…` | תשלום על משמרות שהסתיימו, כתשלום אחד (כמו באתר) |
| `left-open` | משמרת שנשארה פתוחה מאתמול ב-22:00 (שכחה ללחוץ יציאה) |
| `disconnect` | ניתוק הטלפון (כמו "נתק" במק) |

כל הפקודות עובדות רק על העובדת testing ולא נוגעות בנתונים של אף אחד אחר.
`tools/live-test/shot.sh <name>` — צילום מסך של האמולטור ורשימת הטקסטים והאזורים הלחיצים.

## רשימת בדיקות (נבדקה ב-6/11/2026, הכול עבר)
1. חיבור עם קוד; קוד שכבר שומש נדחה עם הודעה ברורה
2. כניסה, יציאה, ביטול יציאה, ביטול כניסה, יציאה תוך פחות מדקה (המשמרת נמחקת)
3. תיקון שעת כניסה במשמרת פעילה, תיקון משמרת שהסתיימה היום (נשמר ישר + הודעה למנהל)
4. שינוי שלישי באותה משמרת → בקשה לאישור; המשמרת לא משתנה עד האישור
5. הוספת משמרת שנשכחה היום (נשמרת ישר); חפיפה עם משמרת קיימת נחסמת
6. בקשה ליום קודם → `approve` → מופיעה "אושרה" והמשמרת נוספת
7. `pay` → "שולם" בטלפון; שינוי משמרת ששולמה הופך לבקשה; `reject` → "נדחתה"
8. ביטול בקשה ממתינה
9. מצב טיסה: כניסה ויציאה בלי קליטה ("לא נשלח עדיין"), גם אחרי סגירת האפליקציה, ואז סנכרון עם השעות האמיתיות
10. התראת "את במשמרת" ויציאה מתוך ההתראה; אריח בהגדרות המהירות (כניסה ויציאה)
11. `left-open` → באנר "שכחת ללחוץ יציאה?" → רישום שעת היציאה האמיתית
12. מעבר בין חודשים; סכומים בטלפון = `totals`
13. `disconnect` → מסך חיבור, גם אחרי הפעלה מחדש; חיבור מחדש עם `code`; הסרה והתקנה → חיבור אוטומטי
